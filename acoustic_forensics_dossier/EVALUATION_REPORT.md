## 2. Problem Definition & Evaluation Framework

### 2.1 Task Formulation
- **Classification Objective**: Given a single-channel audio recording $x \in \mathbb{R}^N$ sampled at 16,000 Hz, predict the posterior probability $P(y = 1 \mid x) \in [0, 1]$, where:
  - $y = 1$: **Bona Fide** (Authentic human phonation recorded through a physical microphone).
  - $y = 0$: **Spoof** (Synthetic speech generated via text-to-speech vocoders or voice conversion algorithms).
- **Secondary Objective**: Compute a frame-level temporal attention salience vector $\alpha \in \mathbb{R}^T$ indicating which phonetic frames drove the classification decision.

### 2.2 Biometric & Forensic Metrics
1. **Equal Error Rate (EER)**: The operating threshold where the False Acceptance Rate ($\text{FAR} = \text{FP} / (\text{FP} + \text{TN})$) equals the False Rejection Rate ($\text{FRR} = \text{FN} / (\text{FN} + \text{TP})$).
2. **ROC-AUC & PR-AUC**: Area under the Receiver Operating Characteristic and Precision-Recall curves.
3. **Minimum Tandem Detection Cost Function (min-tDCF)**: The official ASVspoof metric evaluating the countermeasure operating in tandem with an automatic speaker verification (ASV) system:
   $$\text{tDCF}(s) = C_{\text{miss}} \cdot P_{\text{tar}} \cdot P_{\text{miss}}^{\text{cm}}(s) + C_{\text{fa}} \cdot P_{\text{non}} \cdot \frac{P_{\text{fa}}^{\text{asv}}}{1 - P_{\text{miss}}^{\text{asv}}} + C_{\text{fa}} \cdot P_{\text{spoof}} \cdot P_{\text{fa}}^{\text{cm}}(s)$$
   Parameters: $P_{\text{tar}} = 0.05, P_{\text{non}} = 0.05, P_{\text{spoof}} = 0.90, C_{\text{miss}} = 1.0, C_{\text{fa}} = 10.0$.
4. **Sign Convention**: Continuous score $s \in (-\infty, +\infty)$ where higher values indicate bona fide speech ($s > \theta \implies \text{Genuine}$).

## 4. Methodology & Model Architectures

### 4.1 Feature Extraction Pipeline
- **Audio Preprocessing**: Monophonic 16 kHz PCM audio normalized to peak amplitude $\le 1.0$. Fixed-length windowing to 4.0 seconds ($64,000\text{ samples}$) via center-cropping or circular repeat-padding (`src/acforensics/data/segmentation.py`).
- **LFCC (Linear Frequency Cepstral Coefficients)**:
  - 60 coefficients ($20\text{ static} + 20\ \Delta + 20\ \Delta\Delta$).
  - $N_{\text{fft}} = 512$, window length = 400 (25 ms), hop length = 160 (10 ms), 20 linearly spaced triangular filters spanning $0\text{ Hz} - 8,000\text{ Hz}$.
  - Cepstral Mean and Variance Normalization (CMVN) applied globally using stats fitted strictly on TRAIN.
- **Log-Mel Filterbanks**:
  - 80 Mel-frequency channels spanning $0\text{ Hz} - 8,000\text{ Hz}$, power = 2.0, dynamic range = 80 dB.
- **Statistical Feature Pooling (Classical Baselines)**:
  - Utterance-level concatenation of frame-wise mean and standard deviation: $2 \times F = 120\text{ dimensions}$ for LFCC, $160\text{ dimensions}$ for Log-Mel (`src/acforensics/models/classical.py`).
  - Train-fitted PCA reducing 120-dim LFCC to 40 orthogonal components (95.1988% explained variance).

#### 1. CRNN Architecture (`src/acforensics/models/crnn.py`)
- **CNN Spectral Encoder**: 4 stages of ConvBlock (`Conv2D(3x3) -> BatchNorm -> ReLU -> Conv2D(3x3) -> BatchNorm -> ReLU -> MaxPool2D(2x2) -> SpatialDropout(0.1)`). Channel progression: $32 \rightarrow 64 \rightarrow 128 \rightarrow 128$.
- **Recurrent Modeling**: 2-layer Bidirectional GRU (hidden size = 128 per direction, concatenated output = 256, dropout = 0.3).
- **Self-Attention Mechanism**: 4-head Multi-Head Self-Attention (embed dim = 256, dropout = 0.1) with residual LayerNorm.
- **Attention Pooling**: Trainable scoring vector $w \in \mathbb{R}^{256}$ computing temporal weights $\alpha_t = \frac{\exp(w^T \tanh(W h_t))}{\sum_{\tau} \exp(w^T \tanh(W h_\tau))}$.
- **Classifier Head**: Linear($256 \rightarrow 128$) $\rightarrow$ ReLU $\rightarrow$ Dropout($0.3$) $\rightarrow$ Linear($128 \rightarrow 2$).
- **Optimizer & Schedule**: AdamW ($\text{lr} = 0.0010$, weight decay = $0.0001$), `ReduceLROnPlateau` scheduler (factor = 0.5, patience = 2), gradient clip norm = 5.0.

#### 2. Classical Baselines (`src/acforensics/models/classical.py`, `gmm.py`)
- **GMM**: 64 diagonal covariance components trained with Expectation-Maximization on frame features. Continuous score = Log-Likelihood Ratio.
- **RBF-SVM**: Support Vector Classifier with RBF kernel ($C=1.0, \gamma=\text{'scale'}$), balanced weights on 40-dim PCA features.
- **Random Forest**: 200 estimators, balanced subsampling, maximum depth = 20.
- **Logistic Regression**: $L_2$ regularization, $C=1.0$, L-BFGS solver.

#### 3. Stacked Ensemble Fusion (`src/acforensics/ensemble/stacking.py`)
- Standardizes 6 continuous predictions via Dev-fitted mean and variance: $z_i = \frac{s_i - \mu_i}{\sigma_i}$.
- Fits an $L_2$-regularized Logistic Regression meta-learner on $z \in \mathbb{R}^6$ to optimize cross-entropy on DEV:
  $$s_{\text{fused}} = \beta_0 + \sum_{i=1}^6 \beta_i z_i,\quad P(\text{Bona Fide} \mid x) = \sigma(s_{\text{fused}})$$

## 6. Controlled Scientific Ablation Studies

### 6.1 Feature Representation: Linear Frequency Cepstral Coefficients vs. Log-Mel
*Source: `results/tables/feature_ablation.csv`*

| Feature Representation | Input Dimension | Dev EER (%) | Eval EER (%) | Eval ROC-AUC | Eval min-tDCF |
|:---|:---|---:|---:|---:|---:|
| **LFCC (Proposed)** | 60 ($20\text{ static} + 20\ \Delta + 20\ \Delta\Delta$) | **0.0000%** | **0.0000%** | **1.0000** | **0.0000** |
| **Log-Mel Filterbanks** | 80 Mel-frequency channels | 67.5000% | 60.0000% | 0.4356 | 1.0000 |
| **LFCC + Log-Mel Fusion**| 140 combined spectral channels | 26.2500% | 13.7500% | 0.9625 | 0.2315 |

*Scientific Interpretation*:
- **Acoustic Physics of Deepfakes**: Modern neural vocoders (WaveNet, HiFi-GAN) model human speech by conditioning on Mel spectrograms. Because they are trained to optimize perceptual Mel-domain loss functions, they introduce phase inconsistencies, unnatural harmonic ripples, and high-frequency spectral tilt anomalies in the physical linear spectrum ($3\text{ kHz} - 8\text{ kHz}$).
- **The LFCC Advantage**: By computing filterbanks across a **linear frequency axis**, LFCC preserves these high-frequency vocoder imperfections, giving the CRNN decisive discriminative features. In contrast, Log-Mel compresses high frequencies, effectively erasing the vocoder's forensic signature.

## 9. Key Limitations & Risk Mitigations

1. **Low-Bitrate Compression Loss**: Audio encoded via AAC at $\le 32\text{ kbps}$ degrades classification performance (+31.25 pts EER at 16 kbps).  
   *Mitigation*: The web application inspects file headers and flags bitrates $< 32\text{ kbps}$ with an explicit warning banner advising secondary biometric corroboration.
2. **Short Utterance Padding**: Utterances $< 1.0\text{ second}$ require circular repeat-padding.  
   *Mitigation*: The validation stage enforces a minimum duration of 0.5 seconds, rejecting clipped sound bites.
3. **Multi-Seed Variance Run**: Full 3-seed statistical variance bounds (`results/metrics/crnn_lfcc_multiseed_summary.json`) require running the long-duration script `scripts/train_crnn.py --seeds 42 1337 2024`.
